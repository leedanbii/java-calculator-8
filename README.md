# **문자열 덧셈 계산기**

## 📌 **요구 사항**

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

쉼표(,) 또는 콜론(:) 기본 구분자 외에도 커스텀 구분자를 지정해 입력할 수 있다.

잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료된다.

# 📍 기능 목록

## 기본 기능

- 빈 문자열을 입력하는 경우 0을 반환한다.
- 하나의 숫자를 입력하는 경우 해당 숫자를 반환한다.
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.

## 커스텀 구분자 기능

- 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.

## 입출력 기능

- 사용자가 입력하는 값은 `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용한다.
- 계산 결과는 `System.out.println()`을 활용해 출력한다.

## 예외처리 기능

- 잘못된 값을 입력한 경우 `IllegalArgumentException`을 발생시킨다.
    - 음수, 숫자가 아닌 문자
- 프로그램 종료 시 `System.exit()`를 호출하지 않는다.

## 📝 **프로그래밍 요구 사항**

✔ JDK 21 버전에서 실행 가능해야 한다

✔ 프로그램 실행의 시작점은 `Application`의 `main()`

✔ `build.gradle` 파일은 변경할 수 없으며, **제공된 라이브러리 이외의 외부 라이브러리는 사용 X**

✔ 자바 코드 컨벤션을 준수한다

## 💡예외 처리 및 코드 구조 설계

이번 미션에서는 예외 처리의 명확성과 코드 가독성을 최우선으로 고려했습니다.

“입력값 처리 → 입력값 검증 → 예외 발생”의 흐름이 자연스럽게 이어지도록 설계했습니다.

또한, 하나의 메서드가 여러 역할을 하지 않도록 코드를 세분화하여 유지보수성과 가독성을 높였습니다.

## 예외 처리

- 잘못된 입력값: 숫자가 아닌 문자가 포함될 경우 `NumberFormatException`을 `IllegalArgumentException` 으로 변환
- 음수 입력: 0 미만의 숫자 입력 시 `IllegalArgumentException` 발생
- 빈 문자열 입력: 기본값 0 반환

## 코드 구조

- 메서드를 역할별로 분리하여 가독성과 유지보수성을 높임

| 메서드 | 역할 |
| --- | --- |
| `add()` | 입력 검증 및 합산 제어 |
| `splitNumbers()` | 구분자 처리 및 파싱 |
| `sum()` | 숫자 배열 합산 |
| `positiveParseInt()` | 입력값 검증 및 변환 |
